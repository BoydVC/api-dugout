How to use the dugout

  1. ◆ Diamond: drag fielders (P, C, 1B…RF). Draw Throw, Run, or Cutoff arrows.
  2. Build a play: set up frame 1, tap ＋ Frame, move fielders, repeat. Press ▶ to watch coverage unfold.
  3. Presets: load a generic defensive example (steal, bunt, cutoff, 1st-and-3rd, relay, rundown). Teaching only — not from a real game.
  4. 📋 Lineup: edit batting order 1–9 + EH. Starts as Player 1… — your family fills names.
  5. 📊 Scorebook: empty inning grid. Tap cells to mark. No scores pre-filled.
  6. 📝 Practice: blank crib cards for whatever you want to remember — not a schedule.
  7. Save PNG exports the current diamond frame with a title band.

Keys: Space play/pause · ←/→ step · Ctrl+Z undo · M/T/R/C/E tools.
Private: no account, no upload, binds to 127.0.0.1 only.
